# Glossary

Plain-language definitions of the terms used across the colander
documentation. The table is alphabetical; the last column links to the page that
explains the term in depth.

| Term                | Definition                                                                                                                                                                                                                                                                                                                                                                                                                            | More                                                           |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| ABI                 | The binary calling convention through which hosts call the compiled shared library. In colander it is twelve exported C functions that take and return NUL-terminated UTF-8 JSON strings.                                                                                                                                                                                                                                             | [entry-points.md](entry-points.md), [abi.md](abi.md)           |
| ABI version         | The integer identifying the ABI surface, defined as `ABI_VERSION 1` in the header and returned by `colander_abi_version()`. Check it at startup and refuse to run on a mismatch.                                                                                                                                                                                                                                                      | [abi.md](abi.md)                                               |
| key-sorted form     | Writing JSON with object keys sorted by UTF-8 byte order, no whitespace, and number literals preserved exactly. `colander_compile` emits key-sorted documents; `colander_content_hash` hashes documents in their own order instead. Called "canonical", "canonicalize" or "canonical documents" as shorthand elsewhere and in code identifiers, which are unchanged; it is not RFC 8785 and no interop with that standard is offered. | [json.md](json.md)                                             |
| code                | A field's answer key. It keys the `values` input to `colander_evaluate_rules` and the `calculatedValues` output, and expressions reference fields by code.                                                                                                                                                                                                                                                                            | [concepts.md](concepts.md), [documents.md](documents.md)       |
| component reference | A form field of `type: "component-ref"` that `colander_compile` replaces with a `group`, resolving the referenced `(code, version)` against the `components` batch in the request.                                                                                                                                                                                                                                                    | [documents.md](documents.md)                                   |
| content hash        | A lowercase hex SHA-256 digest. `colander_compile` hashes the compiled triple; `colander_content_hash` hashes a form/ui/rules payload as given. A component's `contentHash` pin is that digest over the component's own compiled triple, and `colander_compile` verifies it (SPEC P-3).                                                                                                                                               | [json.md](json.md), [entry-points.md](entry-points.md)         |
| envelope            | The single JSON object every `char *`-returning function returns: `{"ok":true,"result":{…}}` on success, or `{"ok":false,"error":{"kind","message"}}` on failure.                                                                                                                                                                                                                                                                     | [abi.md](abi.md)                                               |
| expression          | A rule value that is either a reference (`{"ref":"field_code"}`), a literal (`{"lit":…}`) or an operation (`{"op":"eq","args":[…]}`).                                                                                                                                                                                                                                                                                                 | [rules.md](rules.md)                                           |
| field code          | See `code`. The answer key for a field, distinct from its id.                                                                                                                                                                                                                                                                                                                                                                         | [concepts.md](concepts.md)                                     |
| field id            | A field's stable identifier. The UI and rules documents are keyed by it, and the `visibility`, `enabled` and `required` maps are keyed by it.                                                                                                                                                                                                                                                                                         | [concepts.md](concepts.md), [documents.md](documents.md)       |
| form schema         | The document that defines the field tree: `schemaVersion`, an optional `$schema`, and a `fields` array.                                                                                                                                                                                                                                                                                                                               | [documents.md](documents.md)                                   |
| golden vector       | One frozen recorded test case under `tests/golden/vectors/`. There are 249 cases across seven files, replayed through the C ABI. The seven groups are all in this repository.                                                                                                                                                                                                                                                         | [vectors.md](vectors.md)                                       |
| literal (`lit`)     | An expression node carrying any JSON value. A node with a non-empty `ref` is a reference instead; otherwise `lit` wins over `op`.                                                                                                                                                                                                                                                                                                     | [rules.md](rules.md)                                           |
| normalized answers  | The compact JSON object returned as `normalizedAnswersJson`: only the answers that were accepted and converted, keyed by field code in form order.                                                                                                                                                                                                                                                                                    | [validation.md](validation.md)                                 |
| operator            | The `op` of an expression, such as `eq`, `and` or `add`. Each operator has a fixed arity and a documented comparison, truthiness or emptiness rule.                                                                                                                                                                                                                                                                                   | [rules.md](rules.md)                                           |
| reference (`ref`)   | An expression node with a non-empty `ref`, which resolves to the current value of a field by its code (or `null` if unknown).                                                                                                                                                                                                                                                                                                         | [rules.md](rules.md)                                           |
| repeater            | A field of `type: "repeater"` whose answer is an array of row objects, optionally bounded by `minItems` and `maxItems`.                                                                                                                                                                                                                                                                                                               | [documents.md](documents.md), [validation.md](validation.md)   |
| request             | One NUL-terminated UTF-8 JSON string passed to an entry point (or `NULL`). It must parse to a JSON object unless a specific entry point says otherwise.                                                                                                                                                                                                                                                                               | [abi.md](abi.md)                                               |
| response            | The JSON envelope an entry point returns. Its `result` member holds the entry point's own payload.                                                                                                                                                                                                                                                                                                                                    | [abi.md](abi.md)                                               |
| rules schema        | The document that attaches behaviour to fields by id: `visibleWhen`, `enabledWhen`, `requiredWhen` and `calculate` per field, plus a `validations` array.                                                                                                                                                                                                                                                                             | [rules.md](rules.md), [documents.md](documents.md)             |
| schemaVersion       | The version string carried by a form, and separately by UI and rules documents. A rules document's `formSchemaVersion` must equal the form's `schemaVersion` when both are present.                                                                                                                                                                                                                                                   | [documents.md](documents.md)                                   |
| UI schema           | The presentation document: a `fields` object keyed by field id (only `hidden` is read) and a `layout` array that `colander_compile` rewrites.                                                                                                                                                                                                                                                                                         | [documents.md](documents.md)                                   |
| UTF-16 code unit    | The unit in which `minLength`/`maxLength` and JSON Schema string lengths are counted, matching the JSON Schema specification rather than Unicode scalar values.                                                                                                                                                                                                                                                                       | [documents.md](documents.md), [json-schema.md](json-schema.md) |
